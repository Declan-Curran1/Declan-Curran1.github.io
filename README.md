# declanjacques.blog

Source for Declan Curran's personal website — live at **[declanjacques.blog](https://declanjacques.blog)**.

Built with [Astro](https://astro.build) and Tailwind CSS. Every push to `main` builds and deploys the site automatically.

## Local development

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # production build to ./dist
```

Theme originally based on [Bear Blog](https://bearblog.dev).
